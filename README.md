# โครงการห้องเรียนพิเศษวิทยาศาสตร์–คณิตศาสตร์ ระดับชั้นมัธยมศึกษาตอนต้น
## GIFTED | Science & Mathematics Program
### โรงเรียนสารวิทยา | SARAWITTAYA SCHOOL

เว็บไซต์ทางการแบบ Full-Stack สำหรับโครงการห้องเรียนพิเศษวิทยาศาสตร์–คณิตศาสตร์ ระดับชั้นมัธยมศึกษาตอนต้น โรงเรียนสารวิทยา พร้อมระบบจัดการสารสนเทศ (CMS), คลังความรู้ดิจิทัล, ปฏิทินกิจกรรม, หอเกียรติยศ, พอร์ทัลนักเรียน, พอร์ทัลอาจารย์, ศูนย์ควบคุมผู้ดูแลระบบ (Admin Dashboard), ฐานข้อมูล PostgreSQL, และระบบความปลอดภัย Row Level Security (RLS)

## 3. สถาปัตยกรรมและโครงสร้างเส้นทาง (Information Architecture)

### หน้าสาธารณะ (Public Routes)
- `/` — หน้าหลัก (Hero, แนะนำจุดเน้นโครงการ, ข่าวเด่น, กิจกรรมที่กำลังจะมาถึง, คลังความรู้แนะนำ, หอเกียรติยศ)
- `/about` — เกี่ยวกับโครงการ (เสาหลักการเรียนรู้แบบสืบเสาะ, แล็บทดลอง, ตรรกะคณิตศาสตร์, งานวิจัย)
- `/news` — ข่าวสารและประกาศ (ค้นหา, กรองหมวดหมู่, แบ่งหน้า, เฉพาะข่าวที่เผยแพร่แล้ว)
- `/news/:slug` — เนื้อหาข่าวฉบับเต็ม (Shareable URL, ข่าวที่เกี่ยวข้อง)
- `/calendar` — ปฏิทินกิจกรรม (มุมมองรายเดือน, มุมมองรายการ, กรองหมวดหมู่, เวลา Asia/Bangkok)
- `/activities` — รวมภาพและรายละเอียดกิจกรรมวิชาการ ค่าย และการทดลอง
- `/achievements` — ผลงานและรางวัล (หอเกียรติยศ, กรองตามปีการศึกษาและหมวดหมู่, คุ้มครองข้อมูลส่วนบุคคล)
- `/resources` — คลังความรู้ทางวิชาการ (ค้นหาตามวิชา Physics, Math, Chemistry, Biology, STEM ฯลฯ)
- `/resources/:id` — รายละเอียดเอกสารและดาวน์โหลดตามระดับสิทธิ์
- `/documents` — บริการดาวน์โหลดแบบฟอร์มและคู่มือ
- `/contact` — ช่องทางติดต่ออย่างเป็นทางการของโรงเรียนสารวิทยา พร้อมฟอร์มส่งข้อความ
- `/login` — เข้าสู่ระบบสมาชิก

### หน้าที่มีการคุ้มครองสิทธิ์ (Protected Routes)
- `/student` — พอร์ทัลนักเรียน (ดาวน์โหลดชีทเรียน, ตรวจสอบกำหนดการ, แก้ไขโปรไฟล์)
- `/teacher` — พอร์ทัลอาจารย์ (ส่งร่างข่าว, สร้างกิจกรรม, อัปโหลดเอกสาร, ส่งผลงานขออนุมัติ)
- `/admin` — ศูนย์ควบคุมผู้ดูแลระบบ (สรุปสถิติจริง, ประวัติความปลอดภัย Audit Logs)
- `/admin/news` — จัดการข่าวสาร (เพิ่ม, แก้ไข, ปรับสถานะ เผยแพร่/แบบร่าง/เก็บถาวร, ปักหมุดข่าวเด่น)
- `/admin/events` — จัดการกิจกรรมและปฏิทิน
- `/admin/resources` — จัดการคลังเอกสารและระดับสิทธิ์การดาวน์โหลด
- `/admin/achievements` — ตรวจสอบและอนุมัติผลงานการแข่งขันเข้าสู่หอเกียรติยศ
- `/admin/users` — จัดการผู้ใช้งานและบทบาท (Admin, Teacher, Student) และระงับบัญชี
- `/admin/settings` — ตั้งค่าแถบประกาศด่วนและข้อมูลติดต่อ

## 4. โครงสร้างฐานข้อมูล PostgreSQL & Supabase

ไฟล์ Migration ต้นฉบับอยู่ที่:
`supabase/migrations/20261019000000_init_schema.sql`

ประกอบด้วย:
1. `profiles` — ข้อมูลผู้ใช้ บทบาท และสถานะบัญชี (เชื่อมโยงกับ auth.users)
2. `categories` — หมวดหมู่ข่าว กิจกรรม และทรัพยากร
3. `news_articles` — บทความข่าวสาร พร้อม slug และสถานะ (draft, published, archived)
4. `events` — ปฏิทินกิจกรรม วันเวลา สถานที่ และระดับสิทธิ์การมองเห็น
5. `learning_resources` — คลังความรู้ วิชา ประเภทไฟล์ และระดับสิทธิ์ (public, student, teacher)
6. `achievements` — ผลงานนักเรียน รางวัล ปีการศึกษา และการอนุมัติ
7. `audit_logs` — บันทึกประวัติการกระทำของผู้ดูแลระบบอย่างปลอดภัย

### ขั้นตอนการเชื่อมต่อ Supabase Live Project
1. สร้างโปรเจกต์ใน [Supabase Dashboard](https://supabase.com)
2. เปิดเมนู **SQL Editor** คัดลอกเนื้อหาจากไฟล์ `supabase/migrations/20261019000000_init_schema.sql` ไปวางแล้วกด **Run**
3. คัดลอก **Project URL** และ **Anon Public API Key** มาใส่ในไฟล์ `.env` หรือคลิกปุ่ม **"ตั้งค่าฐานข้อมูล (Supabase)"** ที่มุมขวาล่างของเว็บไซต์
4. ระบบจะเชื่อมต่อและทำงานร่วมกับฐานข้อมูลสดทันที

## 5. การทดสอบและสลับบทบาทผู้ใช้งาน (Interactive Role Preview)

ในหน้า `/login` หรือที่แถบ Header / Sidebar มีปุ่มสลับบทบาทสำหรับทดสอบได้ทันที:
- **Admin (ผู้ดูแลระบบ):** เข้าถึงศูนย์ควบคุม `/admin/*` ทั้งหมด
- **Teacher (อาจารย์ผู้สอน):** ส่งร่างข่าว, เพิ่มกิจกรรม, อัปโหลดเอกสาร, ส่งผลงานนักเรียน
- **Student (นักเรียน):** เข้าถึงพอร์ทัล `/student` และดาวน์โหลดเอกสารเฉพาะนักเรียน
